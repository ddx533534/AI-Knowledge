# 关系类型

关系有方向：源节点 → 目标节点。每条边需要直接证据和解释，不能仅凭相似、共同分类或模型记忆建立。

| 类型 | 源 → 目标的含义 | 使用条件 |
| --- | --- | --- |
| depends_on | 运行或构建依赖目标 | 官方依赖说明或明确源码/构建证据；区分必需与可选 |
| implements | 实现目标协议、规范或抽象 | 明确实现声明或实现代码 |
| extends | 扩展目标能力或机制 | 明确扩展关系；仅功能类似不足 |
| alternative_to | 在特定问题和条件下可替代目标 | 说明替代范围、差异与条件；不自动生成逆向边 |
| integrates_with | 可与目标集成 | 官方集成说明或可核实适配器；说明版本与可选条件 |
| component_of | 是目标的组成部分 | 明确的归属与架构证据 |
| uses | 使用目标机制、工具或技术 | 可核实使用证据；不等同于必需依赖 |
| related_to | 有值得记录且有证据的具体联系 | 必须说明具体联系，不能把它当泛化兜底边 |

关系对象保存在笔记 frontmatter；同一关系在正文用 wikilink 表达并解释。图谱边来自正文链接，字段中的关系类型不会被 Obsidian 原生图谱直接显示为边标签。

来源：[Obsidian Graph view](https://obsidian.md/help/Plugins/Graph%2Bview)。关系分类是本知识库的维护约定。
