# 面试知识体系

计算机基础面试的成体系整理。每个主题一份文档，结论先行，配自绘图，末尾附高频对比表和来源清单。

## 文档

- [[计算机网络面试知识体系]] — 分层模型、TCP/UDP、三次握手与四次挥手、可靠传输、拥塞控制、HTTP 演进、TLS、DNS 与一次完整请求的链路。
- [[操作系统面试知识体系]] — 用户态/内核态、进程与线程、CPU 调度、同步与死锁、虚拟内存与地址翻译、写时复制、IO 模型与多路复用。
- [[数据结构与算法面试知识体系]] — 复杂度分析、线性结构、哈希、树与图、排序、查找、动态规划套路。
- [[计算机组成原理面试知识体系]] — 冯·诺依曼与哈佛结构、数据表示、存储层次与 Cache、流水线与冒险、总线与 IO。
- [[数据库与缓存面试知识体系]] — MySQL 索引与 B+ 树、事务与 MVCC、锁、日志；Redis 数据结构、持久化、缓存三大问题、分布式锁与集群。

## 写法约定

- 每篇按「结论 → 原理 → 高频追问 → 对比速查 → 待核实 → 来源」组织，先给能直接说出口的答案，再补推导过程。
- 图一律自己画成 SVG，放在 `assets/<日期>/` 下，浅色扁平、细边框、颜色只承载含义不承载装饰。
- 结论与数据尽量落到可核查的来源，拿不准的写进「待核实」，不编造。
- 术语保留英文原文（如 TIME_WAIT、MVCC、TLB），中文只做叙述。
