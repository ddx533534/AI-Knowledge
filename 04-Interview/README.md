## 写法约定

- 每篇按「结论 → 原理 → 高频追问 → 对比速查 → 待核实 → 来源」组织，先给能直接说出口的答案，再补推导过程。
- 图一律自己画成 SVG，放在 `assets/<日期>/` 下，浅色扁平、细边框、颜色只承载含义不承载装饰。
- **同一天有多份文档时用 `assets/<日期>-<主题短名>/`**，避免多篇文档的 `figN` 撞号。
- 结论与数据尽量落到可核查的来源，拿不准的写进「待核实」，不编造。
- 术语保留英文原文（如 TIME_WAIT、MVCC、TLB），中文只做叙述。
