# 每日备考看板

备考期间的日任务看板。成品是单文件网页 `每日备考看板.html`，勾选与笔记保存在浏览器本地，不依赖后端、不需要登录。

## 与本库其它目录的关系

其它目录是写给人读的文档，这里放的是**自己用的工具页**。所以有两个特别之处：

- 它不做「一份知识一个文件」的合并整理，一个页面就是一个工具。
- 看板页要能被站点重构时带上统一的导航与排版，因此页面内**硬编码了站点侧边栏**。本库栏目有增减时，`<nav class="nav">` 需要同步改（当前列的是「首页 / 知识 / 实践 / 日报 / 面试 / 看板」）。

## 已收录

### 每日备考看板（2026-10-14 – 10-31）

- **来源**：`E:\AI-Personal\interview-board\index.html`（原项目另存 README 与 `preview.png` 截图）。
- **用途**：跟进小红书面试与 DeepSeek 笔试的备考节奏，逐日勾选早晨基础 / 上午项目 / 下午 AI / 晚上算法四段时间的任务。
- **功能**：按北京时间取当天日期、可切换日期；勾选完成与「今日记录」自动存进 `localStorage`（键 `interview-board-v1`）；可为错题指定复习日期，到期后在「待复习」里出现；支持导出 / 恢复 JSON 备份。
- **容器化改造**：加入站点侧边栏（沿用页面的浅绿主题）；补了 `--accent-soft` 变量；`main` 收进 `.shell > .col`。窄屏时侧栏折叠成横向导航条。
- **内置计划**：`DAYS` 数组里写死了 10-14 到 10-31 每天的任务文案，周末自动换成三段式时间安排。计划变动需直接改这个数组。
- **数据边界**：记录只存在当前设备的当前浏览器，不跨设备同步、不回传到辅导聊天。换浏览器、换地址、清缓存之前先导出备份。
- **部署提醒**：站点每次重建都会用仓库里的这份文件覆盖线上版本；页面上的勾选存在浏览器本地，因此重新部署**不会清掉你的记录**。

## 新增看板页的写法

1. 在 `05-Board` 下放页面，文件名即站点标题（如 `每日备考看板.html`）。
2. 复制现有页面头部的 `:root` 变量与 `<div class="shell">…</div>` 侧边栏结构，把 `./` 那条导航留作 `class="on"`。
3. 页面自带的 `<script>` / `<style>` 原样保留；`site/build.mjs` 只扫描 `*.md`，不会碰它。
4. 重建站点并部署（见根目录 `README.md`）。
