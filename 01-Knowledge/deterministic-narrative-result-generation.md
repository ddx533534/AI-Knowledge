# 冻结内容库的确定性生成与跨语言一致性

<!-- AI:BEGIN -->
## 结论

冻结输入语义与内容版本后，用固定查表与排序规则生成报告；通过内容摘要和 canonical JSON 对照检查 Python/Node 实现的一致性。证据限于该项目的本地移植验证。

## 关键发现

- 生成器启动时校验冻结内容的 SHA-256，版本与输入内容键共同约束结果。
- 会话、随机码、时钟与存储读写不参与报告生成。
- 580组答案逐项对照 Python/Node 完整输出，包含全部96个目标变体和全轴平分样本。
- canonical JSON、摘要、answer_key 和候选排序均参与对照；本地一致性不证明云端持久化行为。
